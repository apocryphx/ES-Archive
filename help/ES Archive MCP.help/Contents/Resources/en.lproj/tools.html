What your AI can do

The capabilities ES Archive MCP hands to a connected assistant.

Once a client is connected, your assistant gains a set of memory tools it can call mid-conversation. You never invoke these yourself — but knowing the shape of them tells you what is reasonable to ask for.

Asking for it in plain language

You do not need any of those names. In conversation, this is enough:

  • "Remember that — I'll want it next time."
  • "What do we already have on this?"
  • "Store this as a decision, and say why."
  • "Link that back to what we concluded in March."
  • "Tag everything from this project."
  • "What haven't we touched in months?"
  • "That memory is wrong now — correct it."

Two different searches

It is worth knowing the difference, because asking for the wrong one gives disappointing results.

  • Semantic search matches meaning. Ask for it when you remember the gist but not the words: "find where we worked out the licensing question."
  • Pattern search matches text, and returns the matching passages with their surrounding lines rather than just naming the memories. Ask for it when you know an exact string: a file path, an error message, a name.
Duplication is discouraged, not blocked

When your assistant stores something, ES Archive MCP answers with how closely it resembles what is already there. That nudge is what keeps an archive from filling with five versions of the same note — but the decision stays with the assistant.

What it cannot do

The tools reach the memory archive and nothing else. They cannot read your files, your mail, or anything else on this Mac, and they cannot send memories anywhere. See Privacy.
