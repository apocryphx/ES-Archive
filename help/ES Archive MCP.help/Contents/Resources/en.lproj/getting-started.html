Getting started

Connect a client once. After that it is invisible.

ES Archive MCP does not need to be kept running. The app you chat with starts it when a conversation needs the archive, talks to it directly over a private pipe, and it winds down with the session. Connecting a client is a one-time step, and you can connect several: each one tells the archive who it is with an --author argument, so Claude, ChatGPT, and a local model each keep to their own persona in one shared archive. Without the argument a client writes as Claude.

Claude Desktop — one click

  1. Choose Help ▸ Connect ES Archive….
  2. Under Connect Claude in one click, click Connect to Claude.
  3. Claude Desktop comes forward and asks you to confirm the install. Approve it.

That builds a connector pointing at this very copy of the app — wherever it is installed — and hands it to Claude Desktop. From then on, Claude Desktop spawns the archive whenever a conversation starts.

Then install the skills

The tools are the instrument; the skills teach Claude how to play it — when to store, how to research, how to curate. They ship inside the app.

  1. In the Connect window (Help ▸ Connect ES Archive…), click Install Claude Skills… under Teach Claude the archive.
  2. Click Read next to any skill to see its text, or Install to hand it to Claude Desktop. A green checkmark marks each skill you have installed.
  3. Claude Desktop comes forward and asks you to confirm each skill. An earlier copy of the same name is replaced, so this is also how you update skills after an app update.

ChatGPT desktop

ChatGPT's desktop app launches stdio MCP servers itself; there is no file to edit, just a form.

  1. Choose Help ▸ Connect ES Archive….
  2. Under Connect ChatGPT desktop, click Copy Command Path.
  3. In ChatGPT, open Settings ▸ Plugins ▸ MCPs ▸ Add. Give the server a name, and leave Type on STDIO.
  4. Paste the path into Command to launch.
  5. Under Arguments, enter --author, click Add argument, and enter ChatGPT in the second row. Leave environment variables, passthrough, and working directory empty.
  6. Click Save, then start a new conversation.

ChatGPT is the persona name its entries will carry; use another if you prefer. To change the arguments later, open the server from the MCPs tab. Switching between STDIO and Streamable HTTP requires uninstalling and adding it again.

LM Studio and other MCP clients

  1. Choose Help ▸ Connect ES Archive….
  2. Under Configure LM Studio or another MCP client, click Copy MCP Configuration.
  3. In LM Studio, choose Program ▸ Edit mcp.json and paste it in. Then load a model that supports tool use.

The configuration is plain MCP-over-stdio, so the same snippet works in any client that can launch a stdio server — the command is simply the path to this app's executable. Its --author is LM Studio; edit the value if you would rather name the persona after the model you run.

Check it worked

Ask your assistant to store something, then start a fresh conversation and ask it to recall the same thing. If it comes back, you are set.

To watch it happen, open Window ▸ Show Archive Scope and leave it in view: a new dot appears as each entry is stored, and dots flash as the assistant reads them.

If the archive tools never turn up, see Troubleshooting.

Give it something to look at

A brand-new archive is empty, which makes it hard to tell whether anything is working. In the Connect ES Archive window, click Import Demo Archive… to merge in a prepared set with tags and links already in place. See Backing up and restoring for what that does and does not do.
