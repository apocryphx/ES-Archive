Getting started

Connect a client once. After that it is invisible.

ES Archive MCP does not need to be kept running. The app you chat with starts it when a conversation needs the archive, talks to it directly over a private pipe, and it winds down with the session. Connecting a client is a one-time step.

Claude Desktop — one click

  1. Choose Help ▸ Connect ES Archive….
  2. Under Connect to Claude Desktop, click Connect.
  3. Claude Desktop comes forward and asks you to confirm the install. Approve it.

That builds a connector pointing at this very copy of the app — wherever it is installed — and hands it to Claude Desktop. From then on, Claude Desktop spawns the archive whenever a conversation starts.

LM Studio and other MCP clients

  1. Choose Help ▸ Connect ES Archive….
  2. Under LM Studio & other MCP clients, click Copy Configuration.
  3. In LM Studio, choose Program ▸ Edit mcp.json and paste it in. Then load a model that supports tool use.

The configuration is plain MCP-over-stdio, so the same snippet works in any client that can launch a stdio server — the command is simply the path to this app's executable.

Check it worked

Ask your assistant to store something, then start a fresh conversation and ask it to recall the same thing. If it comes back, you are set.

To watch it happen, open Window ▸ Show Archive Scope and leave it in view: a new dot appears as each entry is stored, and dots flash as the assistant reads them.

If the archive tools never turn up, see Troubleshooting.

Give it something to look at

A brand-new archive is empty, which makes it hard to tell whether anything is working. In the Connect ES Archive window, click Import Demo Archive… to merge in a prepared set with tags and links already in place. See Backing up and restoring for what that does and does not do.
