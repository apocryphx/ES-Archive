Troubleshooting

The archive tools do not appear in my assistant

  1. Check the server is running: the traffic light in Window ▸ Show Dashboard should be green.
  2. Check a port is actually bound to the persona you are pointing the client at — Settings ▸ Ports. A row that has never been applied is not listening.
  3. Confirm the client's configuration names the same port. Reopen Help ▸ Connect ES Archive…, pick the persona, and copy the configuration afresh.
  4. If the port has Require JWT switched on, a client that does not send a Cloudflare Access token will be refused. Turn it off for local use.

For LM Studio, also confirm the loaded model supports tool use — one that does not will never call the tools, however well it is connected.

Search finds nothing, or the wrong things

Semantic search matches an entry's summary, not its body. An entry stored without one has no vector, so it is invisible to search and appears as an isolated dot in Archive Scope. Open Archive Scope and read the Isolated count in the status line: if it is more than a handful, that is your answer. Ask your assistant to add summaries to those entries.

Right after a restore, or after entries arrive from another Mac through iCloud, vectors are still being computed. Search over those entries sharpens over the next few moments. Watch the similarity edges appear in Archive Scope.

If it never settles, choose Reindex Vectors from the menu-bar item to rebuild them all.

If you are searching for an exact string — a path, an error message, a name — ask for a pattern search instead. See What your AI can do.

A port will not bind

Something else on this Mac is already using it. Pick another number in Settings ▸ Ports and click Apply & Relaunch. The same applies if you assigned one port twice — the pane will tell you which.

Port changes never take effect until you relaunch. If a new binding seems ignored, that is almost always why.

Entries are attributed to the wrong persona

Authorship comes from the port, so this means the client is pointed at the wrong one. Correct the client's configuration, then fold the mis-attributed records into the right persona with Merge… in Settings ▸ Personas. Back up first.

My other Mac does not have the same entries

  • Both Macs must be signed into the same Apple Account with iCloud Drive on.
  • Sync is not instantaneous. Leave both awake and connected for a few minutes.
  • Entries that arrive from another Mac need their vectors computed locally before search reaches them.

If it still will not sync, back up on one Mac and restore on the other — Backing up and restoring. That works with no iCloud at all.

Archive Scope says "No entries yet"

The archive is empty for the persona you have selected. Check the persona picker at the bottom right and try All (witness). If that is empty too, nothing has been stored yet — import the demo archive from Help ▸ Connect ES Archive… to have something to look at.

Still stuck

Report it at github.com/apocryphx/ES-Archive/issues. Include your macOS version, the ES Archive Server version, and which client you are connecting.
