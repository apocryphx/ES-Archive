Keyboard shortcuts

In menu-bar mode these fire only while the status-item menu is open — there is no app menu bar to catch them.

App

ShortcutCommand
⌘,Settings…
⌘HHide ES Archive Server
⌥⌘HHide Others
⌘QQuit ES Archive Server

File

ShortcutCommand
⇧⌘BBack Up…
⇧⌘RRestore…
⌘WClose Window

Back Up and Restore take Shift because ⌘B is Bold inside a text field.

Edit

ShortcutCommand
⌘ZUndo
⇧⌘ZRedo
⌘X · ⌘C · ⌘VCut · Copy · Paste
⌘ASelect All

View

ShortcutCommand
⌥⌘TShow / Hide Toolbar
⌃⌘FEnter / Exit Full Screen

Window and Help

ShortcutCommand
⌘MMinimise
⌘?ES Archive Server Help

Window ▸ Show Archive Scope and Window ▸ Show Dashboard have no shortcuts; use the menu, or the menu-bar item.
