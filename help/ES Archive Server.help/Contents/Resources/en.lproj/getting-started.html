Getting started

Connect a client once. After that it is invisible.

ES Archive Server runs as an app you keep open. It serves the archive over HTTP on this Mac only, binding one port per persona, and accepts no connections from outside the machine.

1. Give a persona a port

A request's identity comes from the port it arrives on, so every client needs a port bound to the persona it should write as. Choose ES Archive Server ▸ Settings…, open the Ports tab, add a row, pick the persona, and click Apply & Relaunch. See Personas.

2. Point a client at it

  1. Choose Help ▸ Connect ES Archive….
  2. Pick the persona you want this client to write as — the menu lists each one with its port.
  3. Click Copy Configuration.
  4. In LM Studio, choose Program ▸ Edit mcp.json and paste it in. Then load a model that supports tool use.

The configuration names the server after the persona, so configurations for two personas can live in the same mcp.json without overwriting each other.

The endpoints

AddressFor
http://localhost:<port>/mcpMCP over HTTP. The usual choice.
http://localhost:<port>/sseClients that want server-sent events.
http://localhost:<port>/personasRead-only: which port serves which persona.
If the port requires a token

A port set to require a Cloudflare Access JWT will refuse a client that does not send the Cf-Access-Jwt-Assertion header — the pasted configuration alone will not connect. The Connect window warns you in orange when the persona you picked is gated.

Check it worked

Ask your assistant to store something, then start a fresh conversation and ask it to recall the same thing. If it comes back, you are set.

To watch it happen, open Window ▸ Show Archive Scope and leave it in view: a new dot appears as each entry is stored, and dots flash as the assistant reads them.

The Window ▸ Show Dashboard window logs every tool call as it arrives, alongside live entry and vector counts.

If the archive tools never turn up, see Troubleshooting.

Give it something to look at

A brand-new archive is empty, which makes it hard to tell whether anything is working. In the Connect ES Archive window, click Import Demo Archive… to merge in a prepared set with tags and links already in place. See Backing up and restoring for what that does and does not do.
